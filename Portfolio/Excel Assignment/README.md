# Excel Sales Data Analysis

## Project Overview

This project demonstrates the use of **Microsoft Excel for sales data analysis**. The assignment focuses on organizing sales data, performing calculations, applying Excel functions, and summarizing important business information such as total revenue, average revenue, category performance, and regional orders.

## Dataset

The dataset contains sales transaction information, including:

* **Order ID** – Unique identification number for each order
* **Salesperson** – Name of the salesperson
* **Region** – Sales region
* **Product** – Product sold
* **Category** – Product category
* **Units** – Number of units sold
* **Unit Price** – Price per unit
* **Revenue** – Revenue generated from each order

## Tools Used

* Microsoft Excel
* Excel Tables
* Excel Formulas and Functions
* Lookup Functions
* Sorting and Filtering

## Analysis Performed

The assignment includes several sales analysis tasks:

* Calculated revenue using units sold and unit price
* Calculated **total revenue**
* Calculated **average revenue**
* Calculated **total revenue for the Electronics category**
* Calculated **average revenue for Electronics**
* Identified the **maximum revenue**
* Identified the **minimum revenue**
* Counted orders from the **North region**
* Counted the **total number of records**
* Counted numeric revenue cells
* Practiced lookup functions using a lookup table
* Sorted and filtered sales records

## Example Revenue Calculation

Revenue is calculated by multiplying the number of units by the unit price:

`Revenue = Units × Unit Price`

Example Excel formula:

`=F2*G2`
