# 📚 Bookstore Data Analysis Using Tableau

## Project Overview

This project uses **Tableau** to analyze bookstore data and create interactive visualizations that explore book popularity, customer checkout behavior, pricing, discounts, genres, formats, ratings, print run sizes, writing time, and publication editions.

The goal of the project is to transform bookstore data into meaningful visual insights and identify patterns and relationships among different book-related variables.

## Tool Used

* **Tableau**
* Data visualization
* Dashboard development
* Calculated fields
* Filters and sorting
* Trend and correlation analysis

## Analysis Performed

### 1. Most and Least Popular Books

The analysis compares books based on sales and checkout activity.

Visualizations include:

* Top 15 selling books
* Lowest selling books
* Top 15 checkout books
* Comparison of book popularity

This analysis helps identify which titles have the highest and lowest levels of customer activity.

### 2. Checkout, Print Run Size, and Rating Analysis

Scatter plots and trend lines were used to examine relationships among:

* Number of book checkouts
* Print run size
* Book ratings
* Genre

The analysis explores whether books with larger print runs or higher ratings tend to receive more checkouts.

### 3. Writing Time and Page Count Analysis

The project examines relationships between:

* Writing hours and number of checkouts
* Writing hours and number of pages
* Genre

Trend lines were used to visualize how these variables relate across different book genres.

### 4. Genre, Format, and Price Analysis

Book prices were analyzed across different genres and formats.

Formats include:

* Hardcover
* Paperback
* Mass-market paperback
* Graphic books
* Board books

The visualization makes it possible to compare pricing patterns across genres such as Fiction, Mystery, Memoir, Nonfiction, and Children's books.

### 5. Discount Analysis

Discounts were analyzed by different bookstore characteristics, including:

* Publisher
* Genre

The publisher analysis allows comparison of total discount amounts across different publishers.

### 6. Publication Edition Analysis

The project also examines the time between different editions of the same book.

A visualization was created to identify books with the **longest time between editions**, helping explore publication and re-release patterns.

## Key Insights

The dashboards show that bookstore performance can be evaluated from several perspectives rather than sales alone. Checkout activity provides another measure of book popularity, while genre, format, price, publisher discounts, ratings, print run size, and writing characteristics provide additional context for understanding differences among books.

The visualizations also demonstrate how Tableau can be used to identify outliers, compare categories, investigate relationships between variables, and communicate bookstore data in an accessible visual format.
