# Employee Management System Using MySQL

## Project Overview

This project demonstrates the use of **SQL and MySQL** to manage and analyze employee-related data. The assignment focuses on writing SQL queries to retrieve, filter, organize, and summarize information from an employee management database.

The purpose of this project is to practice fundamental SQL concepts and develop skills for working with relational databases.

## Database

The Employee Management database contains employee-related information that can be used to answer different business questions.

The analysis includes working with information such as:

* Employee details
* Employee designations
* Departments
* Salaries and pay information
* Reporting relationships
* Employee IDs and related records

## Analysis Performed

The project includes SQL queries for tasks such as:

* Retrieving employee information
* Listing unique employee designations
* Filtering employees based on specific conditions
* Identifying employees who do not report to another employee
* Sorting employee records
* Counting employees
* Analyzing salary and pay information
* Combining information from multiple tables using joins
* Grouping and summarizing employee data
* Using CTEs and window functions for more advanced analysis

## Example Query

```sql
SELECT DISTINCT designation
FROM employee;
```

This query returns the different employee designations available in the employee table.
