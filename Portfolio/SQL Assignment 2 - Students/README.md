# High School Students Data Analysis Using MySQL

## Project Overview

This project demonstrates the use of **SQL and MySQL** to analyze a high school student dataset. The assignment focuses on writing SQL queries to retrieve, filter, sort, group, and summarize student information.

The purpose of this project is to strengthen fundamental SQL skills and practice answering questions from structured student data.

## Dataset

The dataset contains information related to high school students and their academic records. It is used to perform different SQL queries and explore student-related information.

The project includes SQL queries for tasks such as:

* Retrieving student records
* Selecting specific columns
* Filtering students based on different conditions
* Finding unique values using `DISTINCT`
* Sorting student data
* Counting student records
* Calculating average values
* Finding minimum and maximum values
* Grouping students into different categories
* Applying multiple conditions to answer specific questions
* Summarizing student information using aggregate functions

## Example Query

```sql

FROM students;
```

This query retrieves all records from the students table.
